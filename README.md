## 汇海接口对接

接口基于 HTTP 和 UTF-8 JSON，可使用任意编程语言、任意操作系统开发客户端。数据来源、存储方式与界面由对接方自行设计。

建议按以下顺序阅读和实现：

1. 配置平台地址和学校专属令牌，了解学校、测试项目及学生标识。
2. 查询同步目标，确认学校与当前测试项目。
3. 按需分页读取学生名单；每页默认 1000 条，上限 1000 条。
4. 按项目代码、数值编码与时间要求上传原始成绩。
5. 按 HTTP 状态、接收确认和重试规则处理结果。

完整字段、约束与示例以[汇海同步接口文档](docs/汇海同步接口文档.md)为准。成绩上传成功仅表示原始明细已接收，不代表正式成绩保存或评分完成。

## 文档维护

- 接口参数、响应字段或处理规则变化时，同步更新接口文档中的字段说明、约束与调用示例，保持与后端实现一致。
- 接口文档描述对接协议与可观察行为，保持语言和平台无关，不包含特定客户端的内部实现、构建或交接流程。
- 示例使用合成数据和占位地址、令牌；不提交真实凭据、学生身份信息或业务数据。
- README 提供仓库说明与阅读入口，详细接口契约集中维护在对应文档中。
